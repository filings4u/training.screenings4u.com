What's included

Everything needed for the mock-collection portion of training.

The Collector Training Kit combines the physical collection materials and digital reference documents used by one learner to complete the required mock-collection exercises.

01
5 DOT Collection Kits

Five physical collection kits for the learner's required mock collections.

02
10 Federal CCFs

Federal Custody and Control Forms for practice, documentation, and mock scenarios.

03
Mock Collection Checklist

Digital reference checklist used while completing mock collection exercises.

04
Mock Procedures Guide

Digital procedure reference to support the learner through required scenarios.

05
Collection Site Security Guide

Digital guidance covering collection-site control and security practices.

06
Memorandum for Record

Digital reference document for documenting collection events when needed.

07
1 Ball Point Pen

Included for completing the collection documentation used during mock exercises.

08
2 Pairs of Non-Latex Gloves

Protective gloves for the learner's hands-on collection practice.

How the kit is used

Built around the required collector practice workflow.

The supplies are organized around the practical exercises learners complete as part of the DOT specimen collector qualification pathway.

01

Prepare

Use the collection kits, CCFs, checklist, and site-security reference to set up the mock collection correctly.

02

Practice

Complete routine and problem mock-collection scenarios using the supplied physical materials and procedure guide.

03

Document

Practice proper CCF completion and use the supporting digital documents while working through each scenario.
